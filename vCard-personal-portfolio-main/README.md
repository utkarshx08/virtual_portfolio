# 🌐 Virtual Portfolio

A modern, responsive and interactive personal portfolio website built with **HTML5, CSS3 and JavaScript**.

The portfolio is designed to present professional information, technical skills, projects, education, testimonials, blog content and contact information through a clean and developer-focused interface.

🔗 **Live Demo:** https://suryansh-portfolio-08.vercel.app/

---

## 📌 About The Project

This project is a personal developer portfolio created to provide a central place to showcase:

- 👨‍💻 Professional profile
- 📖 About information
- 🎓 Education and resume
- 💻 Technical skills
- 🚀 Projects
- 📝 Blog/articles
- ⭐ Testimonials
- 📬 Contact information

The website focuses on a **responsive layout, modern UI, smooth interactions and easy navigation**.

It is built using vanilla web technologies without depending on a frontend framework such as React, Angular or Vue.

---

## ✨ Features

### 🏠 Portfolio Homepage
A professional landing section introducing the developer and providing quick access to important sections.

### 👨‍💻 About Me
Contains personal and professional information about the developer.

### 🎓 Resume & Education
Displays educational background and professional/resume-related information in a structured layout.

### 💻 Skills Showcase
Presents technical skills and technologies in an organized visual format.

### 🚀 Project Portfolio
Showcases completed projects with relevant information and project links.

### 🔍 Project Category Filtering
Projects can be filtered according to their category.

### 📝 Blog Section
Provides a dedicated section for displaying articles and technical content.

### ⭐ Testimonials
Displays testimonials in a dedicated section.

### 📬 Contact Section
Provides visitors with a way to view contact information and reach the developer.

### 📱 Responsive Design
The interface is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile

### 🎨 Modern UI
The website uses:

- Dark-themed interface
- Hover effects
- Smooth transitions
- CSS animations
- Responsive layouts
- Modern typography
- Interactive components

### ⚡ Smooth Navigation
Navigation between different portfolio sections is designed to provide a smooth browsing experience.
